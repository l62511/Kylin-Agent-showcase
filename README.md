# Kylin Agent Showcase

Kylin Agent 是面向企业级智能运维场景的 Agent 平台项目。本项目入选第 15 届中国软件杯并获得全国三等奖（国三），当前工程版本为 `0.6.254`。

本仓库是展示仓库，不包含 Kylin Agent 源码、模型密钥、生产数据或可直接部署的二进制包。项目后续将作为毕业设计持续迭代，核心实现与完整评测资产暂不公开；这里保留架构说明、工程决策、可验证的评测证据和演示材料，便于评审、答辩和技术交流。

## 项目定位

- 将自然语言运维请求转换为可审批、可审计、可取消、可回放的执行闭环。
- 通过统一执行服务、幂等指纹、租约恢复、有限线程池和有界事件缓冲，控制重复副作用、事件丢失、延迟抖动与内存风险。
- 将安全护栏、凭据声明、数据脱敏、评测追踪和人工接管纳入同一治理边界。

## 已验证的工程证据

以下数字均来自 2026 年 8 月 8 日项目工作区的定向测试记录，不把定向测试冒充全量基准：

| 领域 | 证据 |
| --- | --- |
| 统一执行生命周期 | Chat/A2A 相关定向回归 42 项通过；服务层覆盖并发单飞、冲突、重启复用、取消、回调异常与租约恢复 6 项 |
| 异步路由隔离 | 异步执行器、MCP、A2A、管理端和自动评测路由定向回归 55 项通过 |
| SSE 背压治理 | Chat/A2A 流式回归 38 项通过；覆盖可靠终态、合并/丢弃计数与固定 worker 上限 |
| 输出边界治理 | 3 项新增测试验证 100 MiB 持续输出、20 MiB 执行器输出和超时返回；Docker 有界读取与 socket 响应边界回归通过 |

完整评测中心的任务成功率、工具调用准确率、结果正确性/一致性、事实有据性、延迟、Token 成本和人工接管率将随毕业设计迭代继续补齐；本仓库只发布已经能够从测试和运行记录复核的数字。
