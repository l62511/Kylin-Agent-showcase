# 展示与答辩演示脚本

## 1. 请求到执行闭环

演示一个只读运维请求，展示请求指纹、计划、审批上下文、工具调用、审计记录和最终证据。重点观察：同一请求重复提交不会产生第二次执行。

## 2. 流式与断线恢复

打开 Chat/A2A 流式页面，制造阶段事件背压后刷新连接。重点观察：普通阶段事件可以合并，终态事件仍可回放；客户端按 `Last-Event-ID` 继续消费，而不是按文本猜测重复事件。

## 3. 长任务与容量保护

并发提交超过执行器容量的长任务。重点观察：事件循环保持可用，满载请求得到明确的 503，超过 deadline 得到 504，底层任务未完成前不会错误释放容量。

## 4. 安全与输出边界

展示危险命令、路径穿越、容器标识注入和超大日志输入。重点观察：请求在执行前被拒绝或限界，超大输出带 `truncated` 元数据，敏感字段只显示脱敏值。

## 5. 评测中心

展示任务成功率、工具调用准确率、结果正确性/一致性、事实有据性、响应延迟、Token 成本和人工接管率的报告字段。完整数据集和生产样本不在展示仓库发布。
