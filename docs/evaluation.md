## 企业级评测维度

- **任务成功率**：按任务目标断言，不以 HTTP 200 或模型自报完成作为成功。
- **工具调用准确率**：校验工具名、参数 schema、调用顺序、重复调用和拒绝原因。
- **结果正确性与一致性**：同一请求重复运行、跨实例运行、重连回放均对比规范化结果。
- **事实有据性**：答案中的关键事实必须绑定检索证据、工具返回或审计记录。
- **响应延迟**：记录首事件、首 token、工具完成和终态的 P50/P95/P99。
- **Token 成本**：按请求、工具轮次和模型分别记录输入/输出 token 与重试开销。
- **人工接管**：区分主动审批、风险升级、超时接管和异常兜底，记录介入原因与恢复时间。

## 数据完整性原则

评测报告必须带数据集版本、样本总数、类别分布、split、排除原因、模型/提示词版本和失败样本索引。展示仓库不上传完整数据集，避免把未授权业务样本或毕业设计资产公开。
